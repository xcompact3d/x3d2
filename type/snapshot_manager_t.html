procedure, public :: handle_restart

  • private subroutine handle_restart(self, restart_iter, dt, comm)

    Prepare to continue the snapshot file of the run being restarted. Steps up to the restart time are kept and later ones (written past the checkpoint) are dropped, so the restarted run appends without duplicating them, whatever snapshot frequency wrote the file. The file's layout is kept so the first snapshot can check it still matches the output settings.
