procedure, public :: ensure_probe

  • private subroutine ensure_probe(self, bc_is_100, bc_is_110, cdims, try_full)

    Runs the FFT probe in this process. The probe on a 32^3 grid runs first, in every mode, and gives the context and the heap. When try_full is set, the probe on the cell dimensions cdims runs once after it. A full-grid probe that returns a failure status leaves the small-grid result in place and sets full_failed. A plan that does not fit aborts inside the library, so the caller sets try_full only when the plan fits. Stops the program when the small-grid probe fails. Each probe measures its own context just before its query.

    Type IntentOptional Attributes Name
    class(cuda_memcheck_device_t), intent(inout) :: self
    logical, intent(in) :: bc_is_100
    logical, intent(in) :: bc_is_110
    integer, intent(in) :: cdims(3)
    logical, intent(in) :: try_full

procedure, public :: query_plan_need

  • private subroutine query_plan_need(self, bc_is_100, bc_is_110, cdims, xtdesc_bytes, stat)

    Runs the query-only mode of the FFT workspace query on the cell dimensions cdims. It allocates no workspace and no xtdesc buffer, so the plan cannot abort for lack of memory. xtdesc_bytes is the size of the xtdesc buffer, which the caller knows from the spectral slab. Sets plan_need_bytes when stat is zero.
