Standalone driver for the Poisson solver. It links only the modules that the Poisson solve needs, from the x3d2_poisson CMake target. It builds the mesh and the FFT Poisson solver for the grid and the boundary conditions on the command line. It fills the right-hand side and solves it the requested number of times. It then reports the solve time.

The default right-hand side is cos(2 pi x). This field has zero mean and zero normal derivative at a non-periodic wall. It is valid for every supported combination of boundary conditions. To use another right-hand side, edit fill_rhs and rebuild.

dirichlet is the velocity boundary condition. The pressure gets homogeneous Neumann walls in that direction. The test test_poisson_bc checks the solve for all four boundary condition configurations.

Usage: x3d2_poisson_solver nx ny nz [bc_x bc_y bc_z] [--repeat N] bc_x, bc_y, bc_z: 'periodic' (default) or 'dirichlet'. The value applies to both ends of the direction. A Dirichlet direction needs an odd grid size. --repeat N: number of times to solve (default 1).

subroutine parse_arguments()

Read nx ny nz, then the optional bc_x bc_y bc_z, then the optional --repeat N. The bc values are periodic or dirichlet. The default is periodic. The default for --repeat is 1. Any other input prints one usage line and stops.

subroutine fill_rhs(host_field)

Fill host_field with the right-hand side of the Poisson equation. The routine uses the host-associated mesh, dims and n_pi. Edit this routine to supply another right-hand side, then rebuild. The coordinates are the cell centres from mesh%get_coordinates(i, j, k, CELL). The right-hand side must have zero mean. In every supported combination of boundary conditions, the pressure has periodic or homogeneous Neumann conditions. The default is cos(2 pi x).

subroutine warn_if_rhs_mean_nonzero(host_field)

Warn on rank 0 if the right-hand side does not have zero mean. The solver needs a zero-mean right-hand side for these boundary conditions. It discards the mean component. The solve runs in both cases.
