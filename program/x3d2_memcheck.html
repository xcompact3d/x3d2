Standalone GPU memory estimator for an x3d2 .x3d input file. --static The formula estimate only. (no flag) The formula estimate, then an FFT plan probe on the whole grid. --build The above, then a real case build and one substep on 1 GPU, measured with cudaMemGetInfo, and a CHECK line against the estimate. The probe gives the CUDA context and the NVSHMEM heap of the GPU in use. The GPU-aware IO staging buffer is added by formula. Usage: x3d2-memcheck [--static | --build [--extensive ]]
