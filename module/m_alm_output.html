Per-element load output of the actuator line model (ALM).

Incompact3d writes one file per element; here each actuator line (blade or tower) gets one root-written CSV file, <line name>.load, with a row per element at every output step. Rotor performance goes through m_scalar_series in m_alm.


Uses

    • m_logger
