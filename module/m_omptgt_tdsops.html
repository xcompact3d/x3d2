OpenMP target extension of the tridiagonal solver operators.

The host tdsops_t is built as usual and its coefficient arrays are copied once into device arrays, as cuda_tdsops_t does, so the kernels read them in place instead of mapping them on every launch.

The device arrays are not freed: there is no finaliser, because the intrinsic assignment of a structure constructor would finalise the temporary and release storage the copy still points at. Operators are built once at start-up and live for the whole run, so construct them in place with omptgt_tdsops_init rather than by assignment.
