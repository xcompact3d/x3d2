Single point for x3d2 to report progress, warnings and errors, and to stop the run when something goes wrong.

Messages carry a level: debug, info, warning or error. Those below the threshold set with set_log_level (info by default) are dropped. Debug and info lines go to standard output, warnings and errors to standard error, and every line is flushed so output from different ranks and from a crash is not lost in a buffer.

The logging calls are made on every rank, but by default only rank 0 writes, so a message appears once however many ranks the run has. Pass all_ranks=.true. for something that only some ranks know about; each rank that makes the call then writes, and on a multi-rank run the line starts with the rank that wrote it.

abort_run is how x3d2 stops on an error. It writes the message and takes down the whole job: a plain error stop on one rank can leave the others waiting forever in MPI. check_mpi turns an MPI return code into such an abort. Backends add their own checks on top of abort_run (see m_cuda_errors for CUDA).

str turns numbers into text, so a message can be assembled with //:

call log_info('Checkpoint frequency: '//str(freq))
