Field operation kernels for the OpenMP target backend, following cuda/kernels/fieldops.f90 and the sum/reorder kernels of cuda/kernels/reorder.f90.

Arrays are explicit-shape or assumed-size dummies named in OMP_DEVICE_ADDR (see m_omptgt_common). Pointwise kernels see a field as a flat array of n points, as the CUDA ones sweep the whole block. Kernels on the pencil layout index a DIR_X/Y/Z field as (SZ, n, groups) in the layout of m_ordering, which is not the one the CUDA kernels use: a DIR_X group index is b = y_block + (z - 1)*n_yb_pad, y-blocks fastest with n_yb_pad = ny_padded/SZ of them per z station.

public subroutine labelled_sums(s, g, label, a, b, c, n_label, n_f, n, n_i, n_groups_pad, n_j)

s(1:3, l) += sums of ga, gb and g*c over the points labelled l, as cuda/kernels/fieldops.f90: each thread accumulates runs of equal labels along its pencil and flushes a run when the label changes, so the atomics scale with the label changes rather than the points. Atomics instead of reduction(+:s), which flang cannot do on the GPU for an array whose shape is only known at run time.
