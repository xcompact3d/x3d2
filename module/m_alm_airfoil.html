Static airfoil polars for the actuator line model (ALM).

Ported from Incompact3d's airfoils.f90 (itself taken from CACTUS). An airfoil holds one table of lift, drag and quarter-chord moment against angle of attack for each tabulated Reynolds number. The coefficients at a given (Re, alpha) are found by linear interpolation in alpha within the two bracketing Reynolds-number tables, then linearly in Re. Outside the tabulated Re range the nearest table is used.

File format (.air): a title line containing ':', then the lines Thickness to Chord Ratio: <t/c>, Zero Lift AOA (deg): <alpha_0> and Reverse Camber Direction: <0|1>, followed by one block per Reynolds number: Reynolds Number: <Re>, a column-header line, and rows of AOA[deg] CL CD CM25 terminated by a blank line or the end of file. Every table must span -180 to 180 degrees.
