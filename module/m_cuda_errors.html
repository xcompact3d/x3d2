CUDA and cuFFT counterparts of m_logger's check_mpi: turn a failed return code into a report naming the operation, the rank and the error, followed by an abort of the whole run.

A CUDA failure is local to the rank that sees it, while its partners carry on into MPI and would wait for it forever, so these always abort the job rather than stopping the one rank.


Uses

    • m_logger
