public subroutine filter_field(self, f, xdirps, ydirps, zdirps, component)

Filter one velocity component in all three directions, in place.

Across a free-slip boundary the component along that direction is odd and the other two are even, the same parity split the first derivatives use, so component selects which operator each direction applies.
