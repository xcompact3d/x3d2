public pure function output_field_active(checkpoint_cfg, name) result(active)

Whether a snapshot output field is actually driven at runtime - a field only triggers its associated allocations if BOTH it is listed in output_fields AND snapshotting is enabled. Mirrors the pattern used for keep_pressure (src/case/base_case.f90:120-122), shared by run() and x3d2-memcheck.
